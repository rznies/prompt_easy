Stop re-prompting.
Start getting answers.

Prompt Easy improves your prompt before it reaches the AI — one click inside ChatGPT, Claude, Gemini or Perplexity. 5 seconds upfront, 2 minutes saved on clarification rounds.

Download extension (.zip) GitHub repo

How it works

  1. Type your prompt as usual in any supported AI chat.
  2. Hit the Improve button Prompt Easy adds next to the composer.
  3. Your vague prompt comes back sharp — context, constraints and format included — ready to send.

Under the hood

4 chat adapters

Content-script adapters for ChatGPT, Claude, Gemini and Perplexity behind one interface.

Gemini-powered

Improvement engine calls the Gemini API with a structured prompt template. Bring your own free-tier key.

Rate-limited & reliable

Daily usage cap, retrying LLM client and local settings store. 112 automated tests, all green.

Private by design

Runs in your browser. Your API key never leaves your machine except to call the model.

Install (1 minute)

  1. Download the .zip above and unzip it anywhere.
  2. Open chrome://extensions, turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder. Done.
